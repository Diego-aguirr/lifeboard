# LifeBoard

> Your second brain to learn, organize, and move forward.

Personal web app to manage projects, habits, study, goals, and knowledge — a Trello + Notion + Duolingo blend for one person.

## Stack

- React 19
- TypeScript
- Vite 8
- Tailwind CSS v4
- Vitest

## Getting started

```bash
pnpm install
pnpm dev
```
